01 · 数据结构定义

一个结点 = 数据域 + 指针域

学生最先要建立的心理模型：链表不是“连续排列的值”，而是一串由地址相互连接的结点。

main.c · 结点定义
1typedef struct LNode{
2 int data; // 保存当前元素
3 struct LNode* next; // 保存下一个结点的地址
4} LNode;
怎么读：next 不是“下一个值”，而是下一个结点的地址。指针走到哪里，下一步就访问哪里的结点。

结点内存示意

地址

next指向下一个结点；末尾结点为 NULL

头结点为什么有用？

  • 对空表和非空表统一处理，插入第 1 个位置的代码不必单独改 Head。
  • Head->next 永远就是首元结点。
  • 头结点本身不参与元素编号，也不打印它的 data。

02 · 辅助函数

getLinkLength：用“走一步、数一个”求长度

它不是装饰性函数。插入位置、删除位置能不能执行，都要先用它得到链表长度。

int getLinkLength(LNode* L)

1int getLinkLength(LNode* L)
2{
3 LNode* p = L->next; // 从首元结点开始
4 int cnt = 0;
5 while(p != NULL)
6 {
7 cnt++;
8 p = p->next;
9 }
10 return cnt;
11}

03 · 建表函数

createLinkList：上传代码采用尾插法

尾插法保留输入顺序；头插法会反转输入顺序。讲课时先把“新结点接到哪里”讲清楚，再比较两种方法。

void createLinkList(LNode* L, int n)
createLinkList · 尾插法
1void createLinkList(LNode* L, int n)
2{
3 LNode* tmp = L; // tmp 始终指向尾结点
4 for(int i = 0; i < n; i++)
5 {
6 LNode* newNode = (LNode*) malloc(sizeof(LNode));
7 printf("第%d个元素的值: ", i + 1);
8 scanf("%d", &newNode->data);
9 newNode->next = NULL;
10 tmp->next = newNode; // 新结点接在尾部
11 tmp = newNode; // 更新尾指针
12 }
13}

2进入循环前先准备尾指针。

11tmp 跟着移动到新尾结点，下一轮才能继续接在后面。

边界提醒：若 n=0，原代码不会建立任何数据结点；但 Head->next 没有显式设为 NULL，遍历时可能出错。更稳妥的写法是在循环前执行 L->next = NULL。

后插法：输入顺序 = 链表顺序

// 核心连接：接到 tail 后面
tail->next = newNode;
tail = newNode;
Head→10→20→30→NULL

前插法 / 头插法：输入顺序会反转

// 前插法核心：每次都插到 Head 后面
newNode->next = L->next;
L->next = newNode;
Head→30→20→10→NULL

输入仍是 10、20、30，但由于每次都插到最前面，输出顺序变成 30、20、10。

04 · 访问函数

printLinkList：遍历的固定四步

打印、求长度、查找都依赖同一套遍历模板；讲透一次，后面可以让学生自己迁移。

printLinkList
void printLinkList(LNode* L)
{
    LNode* p = L->next;       // 1. 从首元结点开始
    while(p != NULL)          // 2. 还有结点
    {
        printf("%d ", p->data);  // 3. 处理当前结点
        p = p->next;            // 4. 走到下一个
    }
    printf("\n");
}
可迁移模板：初始化工作指针 → 判断非空 → 访问 data → 指针后移。删除和插入只是把“访问 data”换成“找到前驱后改连线”。

05 · 基本操作 · 重点

insertNode：先找前驱，再“先连后、后连前”

插入最容易错的是连接顺序。请让学生记住：新结点先接住原来的后半段，前驱再改指向新结点。

bool insertNode(LNode* L, int val, int index)
insertNode
1bool insertNode(LNode* L, int val, int index)
2{
3 LNode* p = L;
4 int len = getLinkLength(L);
5 if(index < 1 || index > len + 1) return false;
6 for(int i = 1; i <= index - 1; i++)
7 p = p->next; // 找到第 index-1 个结点
8 LNode* newNode = (LNode*) malloc(sizeof(LNode));
9 newNode->data = val;
10 newNode->next = p->next; // 先连后半段
11 p->next = newNode; // 前驱再指向新结点
12 return true;
13}

06 · 基本操作 · 重点

deleteNode：保存目标、跨接指针、释放内存

删除不是把 data 改成 0，而是让前驱结点绕过目标结点，并释放目标结点占用的内存。

bool deleteNode(LNode* L, int index)
deleteNode
1bool deleteNode(LNode* L, int index)
2{
3 LNode* p = L;
4 int len = getLinkLength(L);
5 if(index < 1 || index > len) return false;
6 for(int i = 1; i <= index - 1; i++)
7 p = p->next; // p 最终是待删结点的前驱
8 LNode* newNode = p->next; // 保存待删结点
9 p->next = p->next->next; // 绕过待删结点
10 free(newNode); // 释放内存
11 return true;
12}

删除模板

// 1. 找到前驱 p
// 2. 保存要删除的结点
LNode* victim = p->next;
// 3. 前驱绕过 victim
p->next = victim->next;
// 4. 释放内存
free(victim);

边界与易错点

  • 删除位置必须满足 1 ≤ index ≤ len，不能等于 len+1。
  • p 从 Head 出发，因为删除第 1 个结点时也要改 Head->next。
  • 必须先保存待删结点，否则跨接后无法 free。
  • free 后不能继续使用已释放结点的数据。
07 · 基本操作

findNode：查值，不是查“地址”

函数返回第一次匹配的逻辑位置；如果走到 NULL 还没找到，返回 -1。重复元素默认返回第一个位置。

1int findNode(LNode* L, int val)
2{

9 }

08 · 主函数

main：只负责“按顺序调度”

不要把 main 当成大段算法记。它的任务依次是：创建头结点、建表、打印、插入、删除、查找，并在操作成功时再次打印。

main · 逻辑骨架
int main()
{
    int num;
    scanf("%d", &num);

    LNode* Head = (LNode*) malloc(sizeof(LNode));
    createLinkList(Head, num);
    printLinkList(Head);

    scanf("%d%d", &insertIndex, &insertVal);
    if(insertNode(Head, insertVal, insertIndex))
        printLinkList(Head);

    scanf("%d", &deleteIndex);
    if(deleteNode(Head, deleteIndex))
        printLinkList(Head);

    scanf("%d", &findVal);
    int index = findNode(Head, findVal);
    if(index == -1) printf("未找到该元素\n");
    else printf("位置为: %d\n", index);
}

int findNode(LNode* L, int val){

    int index = 1;
    while(p != NULL && p->data != val){

11 · 课堂收束

最后一分钟：用“前驱、顺序、边界、释放”检查代码

让学生不要靠记整段代码，而是用四个关键词检查自己的单链表程序。

前驱插入、删除都要找到目标位置的前驱，因此 p 从 Head 开始。
顺序插入先连 newNode->next，再改 p->next；否则会丢链。
边界插入允许 1..len+1，删除只允许 1..len。
释放删除要先保存待删结点，跨接后再 free。
首元有效结点从 Head->next 开始，头结点不参与编号。
遍历处理当前结点之后，再执行 p = p->next。

上传代码可以进一步改进的地方

  • malloc 后检查是否返回 NULL。
  • 建表前显式执行 L->next = NULL，覆盖 n=0 的情况。
  • 程序结束前释放所有结点和头结点。
  • 输入位置失败后是否继续执行删除、查找，应按实验要求统一处理。
